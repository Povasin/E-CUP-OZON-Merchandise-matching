1. ОБУЧЕНИЕ Hold-out
успешно разделил ваш исходный файл и сохранил два новых файла в папку assets:

assets/matches_val.parquet — содержит ровно 80 000 пар (отложенная выборка для честной проверки).
assets/matches_train.parquet — содержит оставшиеся 285 654 пары (обучающая выборка).
Что делать дальше: Чтобы все работало правильно, вам нужно немного изменить пути в скриптах, чтобы при обучении использовался только train, а при проверке — val.

Например, для обучения бустинга:

bash
python src/train_boost.py --matches assets/matches_train.parquet
И для локальной проверки метрики:

bash
python -m src.local_eval --method boosted --matches assets/matches_val.parquet
Теперь ваша локальная проверка будет намного честнее имитировать реальный лидерборд!
